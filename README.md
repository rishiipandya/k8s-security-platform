# Kubernetes Runtime Security and Policy-as-Code Drift Detection Platform

A local security prototype for Kubernetes manifest scanning, policy evaluation,
RBAC analysis, configuration drift detection, exception tracking, audit logging,
automated testing, observability, and controlled rollback experiments.

## Project status
Initial project scaffold.

## Safety
The initial version uses local test data. Do not connect it to production
clusters or deploy intentionally insecure workloads to public infrastructure.
